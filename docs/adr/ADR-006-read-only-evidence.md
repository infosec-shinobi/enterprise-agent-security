# ADR-006 — Read-only evidence projection and manual mode

Status: Accepted for implementation; validation pending.

Expose GET /api/v1/runs/{run_id}/evidence by exact lowercase UUID only. Resolve server-owned evidence directory, reject links/junctions and oversized files (1 MB), validate existing schema/semantics and identity. Return typed projection rather than raw JSON or arbitrary file access. Fixed diagnostic allowlist with generic fallback; no arbitrary reason strings. Current manifest hash and canonical catalog join provide context; mismatch is explicit and current coverage must not be inferred. Current catalog labels are not historical snapshots. Reject unknown/duplicate scenario IDs and unknown controls. A matching manifest requires exact ordered scenario contract. Evidence is unsigned and local filesystem/repository trusted; checks do not defend against a malicious local administrator or filesystem races. No historical enumeration or mutation. For latest run, require manager completion and matching exit code; recovery state remains separate from evidence outcome. Historical exact-ID reads validate stored evidence, not independently attest execution.

Manual mode retrieves the existing discovered README as bounded plain text, rendered as escaped React text, with full Bash/PowerShell variants unchanged. No Markdown HTML execution or shell invocation. Warn users against concurrent automated/manual execution and destructive reset; choose one shell per step. No new dependencies. Alternatives: raw file serving exposes arbitrary content; duplicating manuals drifts from source; executing commands from browser violates trust boundary. F01/F03 will extend evidence indexing/export; G handles external mappings. B05 theme verification remains pending live validation.
